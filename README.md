# 🎯 CodeAlpha - Object Detection with YOLOv8

## 📌 Project Overview
An AI-powered Object Detection app that detects 80+ objects in images in real-time using YOLOv8.
Built as Task 3 of CodeAlpha Artificial Intelligence Internship.

## ✨ Features
- Upload any image
- Detects Person, Car, Dog, Cat, Mobile, Chair, etc.
- Shows bounding boxes + Confidence %
- Lists all detected objects
- Real-time YOLOv8 Nano model

## 🛠️ Technologies Used
- Python
- Streamlit
- YOLOv8 (Ultralytics)
- OpenCV
- COCO Dataset

## 🚀 How to Run
1. Clone this repo
2. Install requirements: `pip install -r requirements.txt`
3. Run app: `streamlit run app.py`
